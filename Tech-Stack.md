# Engineering Tech Stack

- **Core Framework:** Next.js 14 (TypeScript, App Router)
- **Styling:** Tailwind CSS (configured for Neo-Brutalist UI) + Radix UI Primitives / shadcn/ui.
- **Database:** PostgreSQL 16
- **ORM:** Prisma
- **Queueing:** BullMQ + Redis
- **Storage:** Local File System (Development) -> MinIO (Production)
- **Media Processing:** FFmpeg (Static binaries integrated via `fluent-ffmpeg`)
- **Machine Learning:** Python 3.11, FastAPI, Ultralytics YOLOv8 (Object/Motion), `face_recognition` library.
- **Containerization:** Docker & Docker Compose (Multi-container orchestration).
