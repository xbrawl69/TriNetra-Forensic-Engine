# Visual Identity: Neo-Brutalist Forensic

The UI must project absolute engineering competence, security, and precision. It should not look like a generic template.

- **Colors:**
  - Background: `#fafafa` (Off-white)
  - Surface: `#ffffff`
  - Borders/Text: `#09090b` (Deep Zinc)
  - Accent/Action: `#2563eb` (Engineered Blue)
  - Destructive: `#ef4444`
- **Typography:**
  - `Inter` or `Geist` for UI elements.
  - `JetBrains Mono` for all hashes, timestamps, metadata, and logs.
- **Components:**
  - Thick borders (`border-2 border-black`).
  - Hard shadows (`shadow-[4px_4px_0px_0px_rgba(0,0,0,1)]`).
  - High contrast. No soft gradients or rounded aesthetic "blobs".
  - Data-dense tables with monospaced identifiers.
